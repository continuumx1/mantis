# Mantis v1.0.0 – Vishwakarma

![Mantis v1.0.0 – Vishwakarma, The Divine Architect: the Mantis mascot holding an architect's compass and scroll in front of a golden blueprint](../images/releases/mantis-v1.0.0-vishwakarma.jpg)

**The Divine Architect** · the first stable release of Mantis

*Every great creation begins with a vision. Every extraordinary structure
begins with an architect.*

## The release name

In Indian tradition, Vishwakarma is the divine architect and master
craftsman, credited with designing cities, palaces and the tools of the gods.
Engineers, architects and artisans across India still honour him each year by
celebrating the tools of their trade. Mantis is a tool for builders: it helps
engineers see the structure they have built, so we named our first stable
release after the architect.

> To the engineers, architects and open-source builders who create the
> invisible foundations of our digital world.

Vishwakarma is the name of the release; the version is **1.0.0** (chart
`1.0.0`, images `cx1tech/mantis:1.0.0-*`). The full story is on the
[release page](https://mantis.continuumx1.com/releases/v1.0.0).

## What's new

- **Deterministic topology.** Namespace, Node, Workload and Dependency views,
  laid out the same way every time with no overlapping cards or lines.
- **Application UI.** Dashboard, resource tables and details, events,
  capacity and a needs-attention list.
- **Live sync.** The engine follows the cluster with Kubernetes watches; the
  UI receives only what changed.
- **Infrastructure reports.** A new service, `mantis-report`, produces
  password-protected (AES-256) PDF reports with topology diagrams,
  inventory, health and findings. See [Infrastructure Reports](../reports.md).
- **Secure sign-in.** No default password: the chart generates one, stored
  only as a bcrypt hash, with failed sign-ins throttled.
- **Three services.** `mantis-web`, `mantis-engine` and `mantis-report`. See
  [Architecture](../architecture.md).

The complete list is in the
[changelog](https://github.com/continuumx1/mantis/blob/main/CHANGELOG.md).

## Install

```bash
helm install mantis oci://registry-1.docker.io/cx1tech/mantis \
  --version 1.0.0 --namespace mantis --create-namespace
```

Then follow [Getting Started](../getting-started.md) to sign in.

## Upgrade from 0.3.0

```bash
helm upgrade mantis oci://registry-1.docker.io/cx1tech/mantis \
  --version 1.0.0 --namespace mantis --reset-then-reuse-values
```

- Use `--reset-then-reuse-values` (Helm 3.14+) or your values file. Plain
  `--reuse-values` keeps the 0.3.0 values, which lack the new `auth` and
  `report` settings, and the upgrade fails.
- The `admin`/`admin` login is gone. Read the generated password from the
  Secret the install notes name (`mantis-admin` for a release named
  `mantis`), or set `auth.adminPassword`.
- RBAC adds the read-only `watch` verb and `list` on `events` and metrics
  `nodes`. There are still no write verbs.
