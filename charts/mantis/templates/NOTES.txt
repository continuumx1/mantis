Mantis {{ .Chart.AppVersion }} is installed in namespace "{{ .Release.Namespace }}".

1. Wait until all Pods are Running (about a minute):
     kubectl get pods -n {{ .Release.Namespace }} -l app.kubernetes.io/instance={{ .Release.Name }}

2. Open Mantis:
{{- if .Values.web.ingress.enabled }}
{{- range .Values.web.ingress.hosts }}
     http{{ if $.Values.web.ingress.tls }}s{{ end }}://{{ .host }}
{{- end }}
{{- else if eq .Values.web.service.type "LoadBalancer" }}
     kubectl get svc {{ include "mantis.web.fullname" . }} -n {{ .Release.Namespace }} -w
   and open the EXTERNAL-IP once it is assigned.
{{- else if eq .Values.web.service.type "NodePort" }}
     kubectl get svc {{ include "mantis.web.fullname" . }} -n {{ .Release.Namespace }}
   and open <any-node-ip>:<the NodePort listed>.
{{- else }}
     kubectl port-forward -n {{ .Release.Namespace }} svc/{{ include "mantis.web.fullname" . }} 8081:{{ .Values.web.service.port }}
   then open http://localhost:8081
{{- end }}

3. Sign in as "{{ .Values.auth.adminUsername | default "admin" }}".
{{- if .Values.auth.existingSecret }}
   The password is in your Secret "{{ .Values.auth.existingSecret }}".
{{- else if .Values.auth.adminPassword }}
   Use the password you set in auth.adminPassword.
{{- else }}
   A password was generated for you. Read it with:
     kubectl get secret {{ include "mantis.admin.secretName" . }} -n {{ .Release.Namespace }} -o jsonpath='{.data.password}' | base64 -d; echo
{{- end }}

Next:
  - Dashboard and Topology show the cluster; press Ctrl K to search.
{{- if .Values.report.enabled }}
  - "Download report" (on the dashboard) exports a password-protected PDF.
{{- end }}
{{- if not .Values.clusterName }}
  - Mantis shows this cluster as "in-cluster". To show a real name, add
      --set clusterName=<name>
{{- end }}
{{- if not .Values.web.ingress.enabled }}
  - To share it beyond your machine, enable the Ingress with TLS
    (web.ingress.*); sessions use Secure cookies over HTTPS.
{{- end }}
